# Editor Mode
**Category:** [[09 - Editor Mode and Mods]]

## What It Is

Editor Mode is the official Lore authoring tool. It is the only paid feature of the client: **R$ 10.00, one-time payment, per account**, with no renewal.

See [[Open Source Model and Monetization]].

## What It Unlocks

* World authoring: continuous map, topography, biomes, points of interest.
* Rule authoring: parameters for [[The Nomad Phase|the Stamina Mechanic]], full loot, respawn, taxes, wipes.
* Narrative authoring: quests, factions, languages, season events and Cataclysm.
* Economic authoring: faucets, sinks, crafting and item quality tables.
* Cultural authoring: Descents, cultures, pantheons, passives, Wraths and Ults — see [[Culture System]].
* Packaging and publishing the Lore, including for sale in the [[Lore Market]].
* Consuming authoring mods (3D model import, assets, tools) — see [[Mods and Extensibility]].

## What It Does Not Unlock

Editor Mode grants **no advantage inside other people's matches**. It is a creation tool, not a gameplay tool.

## Create/Play Boundary

| Action | Payment required? |
|---|---|
| Playing the client | No |
| Playing a community Lore | No |
| Playing the official Lore | Purchase of the Lore in the Market |
| Installing mods | No |
| Creating and publishing a Lore | Yes — R$ 10.00, once |
| Selling a Lore in the Market | R$ 10.00 + 10% per sale |

## Open Questions

* Licensing model for the unlock in client forks (the code is open; the payment gate needs a technical and policy definition).
* Compatibility rules between Editor versions and already-published Lores.
