# Aetherna

Projeto conduzido com ADD (Atena Driven Development): https://github.com/guimariz/atena-driven-development

- Fonte de verdade: `.atena/vault/canon/` (somente registros aprovados pelo dono). Propostas ficam em `.atena/vault/drafts/`.
- `.atena/vault/research/legacy-gdd/` é o GDD antigo (commit 87e671c do repo aetherna-graphify-en): **evidência, não canon**. O conceito antigo (MMO sandbox com Hard Wipe) agora é uma futura fase/campanha.
- Política em `.atena/add.yaml`: commit, merge e publicação exigem aprovação explícita.
- Todo conteúdo cultural/divino deve ter base histórica documentada (registrar fontes).
- Código 100% escrito com IA; assets 3D inicialmente via Tripo Studio.
